Leapstone

붉은 옻칠 보드에서 즐기는 다이아몬드 게임과 할마

친구와 함께도 즐기는, 모두를 위한 차분한 보드게임입니다. 컴퓨터와 대결하거나 친구에게 초대 링크를 보내세요. 무료이고 광고가 없습니다.

브라우저에서 플레이

스크린샷

Leapstone이란

Leapstone은 휴대폰에서 즐기는 다이아몬드 게임(차이니스 체커)과 할마입니다. 보드는 붉은 옻칠과 금빛의 3D 보드입니다. 두 손가락으로 확대하면 어느 구멍이든 쉽게 누를 수 있습니다. 힌트는 없습니다. 실제 보드에서처럼 직접 수를 시험해 보세요.

플레이 방법

  • 컴퓨터와 대결. 쉬움, 보통, 어려움. 인터넷이 필요 없습니다.
  • 친구와 함께. 초대 링크를 보내세요. 친구가 링크를 열면 앱이나 브라우저에서 내 게임에 참여합니다. 한 수당 제한 시간은 직접 정하고, 채팅도 할 수 있습니다.
  • 온라인. 같은 레벨의 다른 플레이어와 하는 빠른 게임으로, 한 수당 30초입니다. 온라인 상대 중 일부는 컴퓨터 플레이어일 수 있습니다.
  • 휴대폰 한 대로. 테이블에 둘러앉아 휴대폰을 돌려 가며 하세요.
  • 순위표. 빠른 온라인 대국에서 이겨 레이팅을 올리고 순위표에서 위로 올라가세요.
  • 오늘의 퍼즐. 매일 새로운 퍼즐이 나오고, 모두에게 같은 퍼즐입니다. 최대한 적은 수로 풀고 연속 기록을 이어 가세요. 인터넷이 필요 없습니다.

두 가지 보드

별 모양 보드
다이아몬드 게임(차이니스 체커), 2, 3, 4, 6명용.
정사각형 보드
할마, 2명 또는 4명용.

플레이 방법

내 말 하나를 옆의 빈 칸으로 한 칸 옮기거나, 옆에 있는 말을 뛰어넘으세요. 뛰어넘은 뒤에는 가능한 만큼 계속 뛸 수 있습니다. 모든 말을 먼저 보드의 반대편으로 옮기는 사람이 이깁니다. 다이아몬드 게임(차이니스 체커)의 전체 규칙이나 할마, Sternhalma의 규칙을 읽어 보세요. 더 많이 이기고 싶다면 다이아몬드 게임 전략 팁이나 2인용 다이아몬드 게임, 6인용 다이아몬드 게임 방법을 읽어 보세요.

무료, 필요한 것은 플레이어 이름뿐

Leapstone은 무료이며 광고, 결제, 추적이 없습니다. 이메일 주소나 비밀번호는 필요 없고, 플레이어 이름만 정하면 됩니다. 데이터를 어떻게 다루는지는 개인정보 처리방침에서, 채팅 규칙은 이용 약관에서 읽어 보세요(둘 다 영어).
